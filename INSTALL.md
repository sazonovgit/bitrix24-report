# Установка на другой компьютер

Готового файла `.exe` нет: на новом ПК нужны Python и копия проекта, затем создаётся ярлык на рабочем столе.

## 1. Скопируйте папку проекта

Перенесите папку `bitrix24-report` (флешка, сеть, архив).

Папку `.venv` копировать не нужно — её создают заново на этом компьютере.

## 2. Установите Python 3.11 или новее

Скачайте установщик с [python.org](https://www.python.org/downloads/). При установке включите **Add python.exe to PATH**.

## 3. Установите приложение

В PowerShell откройте папку проекта (путь подставьте свой) и выполните:

```powershell
cd C:\Users\Имя\bitrix24-report
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
```

Если скрипты не запускаются:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Затем снова выполните команды из шага 3.

## 4. Ярлык на рабочий стол

```powershell
python .\scripts\create_desktop_shortcut.py
```

Появится файл **Отчёт Битрикс24.lnk**. Дальше приложение запускается с этого ярлыка.

## 5. Вебхук Битрикс24

Настройки с предыдущего компьютера сами не переносятся.

1. Запустите приложение.
2. Откройте вкладку **Настройки**.
3. Вставьте URL входящего вебхука с правом **CRM** и сохраните.

Файл настроек создаётся на этом компьютере: `%APPDATA%\bitrix24-report\config.json`.
