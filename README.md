# Отчёт Модули / План-Факт из Битрикс24

Десктоп-приложение для Windows: забирает продажи модулей из Битрикс24 и сохраняет Excel (`.xlsx`) в том же виде, что выгрузка «Прайс_ПланФакт».

Установка на другой компьютер: см. [INSTALL.md](INSTALL.md).

## Что нужно

- Python 3.11 или новее
- Входящий вебхук Битрикс24 с правом **CRM (чтение)**

## Установка

```powershell
cd C:\Users\asazonov\bitrix24-report
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
```

## Запуск

```powershell
python -m report_generator
```

или:

```powershell
bitrix24-report
```

Ярлык на рабочем столе:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\create_desktop_shortcut.ps1
```

или:

```powershell
python .\scripts\create_desktop_shortcut.py
```

Появится файл **Отчёт Битрикс24.lnk**. Он запускает `pythonw.exe -m report_generator` из виртуального окружения проекта.

## Настройка вебхука

1. В Битрикс24 откройте **Разработчикам → Другое → Входящий вебхук**.
2. Включите право **CRM**.
3. Скопируйте URL вида `https://your-portal.bitrix24.ru/rest/1/xxxxxxxx/`.
4. Вставьте его во вкладке **Настройки** приложения и сохраните.

Файл настроек **не лежит в папке проекта**. Он создаётся при первом запуске здесь:

`C:\Users\asazonov\AppData\Roaming\bitrix24-report\config.json`

То же самое: `%APPDATA%\bitrix24-report\config.json`. Кэш смарт-процессов и кодов полей: `mapping.json` в той же папке. В git вебхук не попадает — в чат его присылать не нужно.

Если в Битрикс24 переименовали поля года, нажмите **Обновить схему полей**.

## Как пользоваться

1. Выберите **год** — фильтр сделок по полю «Год» и колонка **Год** в файле; **ЦЕНА ПО**, **ЦЕНА ВНЕДРЕНИЯ** и **СУММА** всегда берутся из полей 2026 года.
2. Отметьте колонки, которые попадут в файл.
3. Укажите путь сохранения `.xlsx`.
4. Нажмите **Сформировать отчет**.

## Колонки

- **Название** — элемент смарт-процесса «Модули»
- **Год** — выбранный в окне; в отчёт попадают только продажи, у которых у сделки в поле «Год» стоит это значение
- **Сделка** — ID сделки; строки без сделки не включаются; сделки в стадии «ПРОБЛЕМЫ С ЗАКУПКОЙ / ОТКАЗ ОТ ПУБЛИКАЦИИ» исключаются
- **Название сделки** — название из CRM, в Excel — гиперссылка на карточку сделки в вашем портале
- **Компания** — клиент из CRM
- **ЦЕНА ПО / ЦЕНА ВНЕДРЕНИЯ** — всегда поля **2026** года (у продажи, при пустых — с карточки модуля)
- **СУММА** — всегда поле **2026** года (у продажи, при пустой — с карточки модуля)
- **План/Факт** — «Факт», если запись с вкладки «Фактические продажи» или сделка в стадии «Выиграли закупку»; иначе «План»

Одна строка Excel — продажа модуля конкретной компании, а не уникальный модуль.
